# Close The Two-Sided Job-Seeking Loop

LevelMatch's vision is to close the full job-seeking loop and match candidates to
roles in a way that benefits **both sides**: candidates get matched, upgraded,
prepped, and applied; hiring managers get better-matched, better-prepared
applicants. The name reflects this two-sided *level match*.

Today LevelMatch covers the first slice (ingest → extract → gap analysis). The loop
extends it through five candidate-side use cases, each a proposed Goal:

1. [[resume-upload-matching]] — upload a resume, get matched to jobs
2. [[resume-upgrade-suggestions]] — propose resume upgrades from market data
3. [[prep-plan-generation]] — propose a prep plan from revised resume + matched job
4. [[prep-plan-followthrough]] — help the candidate follow the plan
5. [[auto-apply]] — apply automatically once the candidate is ready

The use cases are sequenced: each builds on the previous. The hiring-manager side
of the loop (better-matched inbound applicants) is a benefit of the candidate arc;
explicit hiring-manager features are a later horizon.

**Why:** A one-shot gap tool is a feature; the closed loop is the product, and the
two-sided framing is the differentiator.
